  order: 2
---

| | |
|---|---|
| Java | 21 |
| Server | Paper, Purpur, or Folia 1.21 or newer |
| Optional | Vault, PlaceholderAPI |

The sale runs on the container's region. The hologram is a TextDisplay and is removed on that same region scheduler. No hologram plugin is required.

`currency.type: vault` needs Vault and an economy plugin that registers with it. `currency.type: placeholder` needs the give command, and a balance placeholder if you want the plugin to check that the balance actually changed.
